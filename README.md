# HiddenInk

HiddenInk is a modern story-sharing platform where readers can discover stories across different genres and writers can publish their own creations. The platform provides an engaging reading experience while giving authors the freedom to publish under their real name or a pen name.

## Features

### 📖 Read Stories

* Browse stories from various genres.
* Explore stories based on personal interests.
* View story details including title, author, genre, and content.

### ✍️ Write & Publish Stories

* Create and publish original stories.
* Select a genre for each story.
* Publish stories using either a real name or a pen name.

### 🔍 Genre-Based Discovery

* Filter and browse stories by genre.
* Improve content discoverability for readers.
* Organize stories into structured categories.

### 🎨 Modern User Experience

* Responsive design for desktop and mobile devices.
* Clean and intuitive interface.
* Smooth navigation and user interactions.

## Tech Stack

### Frontend

* React
* TypeScript
* TanStack Query
* Tailwind CSS
* shadcn/ui

### State Management & Data Fetching

* TanStack Query for efficient data fetching, caching, and server state management.

## Installation

### Prerequisites

* Node.js (v18 or higher)
* npm

### Setup

1. Clone the repository

```bash
git clone <repository-url>
cd hiddenink
```

2. Install dependencies

```bash
npm install
```

3. Start the backend server

```bash
npm run server
```

4. Start the development server

```bash
npm run dev
```

5. Open the application

```bash
http://localhost:5173
```
